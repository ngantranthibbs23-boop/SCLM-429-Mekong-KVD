# Mekong KVD: Logistics Network Design & Omnichannel D2C

## 1. Project Overview

**Course:** SCLM 429 – Transportation and Logistics Management  
**Project Type:** Academic Group Project  
**Team:** Group Brainy  
**Focus:** Supply Chain Management, Transportation Planning, Material Handling, and Omnichannel Distribution.

This project focuses on improving Mekong KVD's logistics operations by developing an integrated distribution network and proposing an Omnichannel D2C strategy.

The project examines transportation efficiency, industrial park selection, material handling, and customer order fulfillment to support better logistics performance.

## 2. Project Objectives

- Evaluate potential industrial park locations for a centralized Mega Hub.
- Analyze transportation workload and distribution options.
- Develop a transportation strategy for B2B partners.
- Improve product protection during warehouse handling and transportation.
- Evaluate Multichannel and Omnichannel D2C models.

## 4. Key Project Outcomes

- Selected Binh Minh Industrial Park as the proposed Mega Hub location, with a weighted score of 4.4/5.
- Proposed a centralized distribution network serving 15 B2B partners.
- Developed a hybrid transportation strategy using four delivery clusters.
- Recommended an Omnichannel D2C model with MFC and BOPIS fulfillment options.
- Proposed protective packaging and standardized material handling procedures.
